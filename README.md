# 買夠（試玩）

第一人稱的台式閾限空間漫遊：一座以老商場為底、會讓人迷路的地方。沒有目的、沒有通關，只有一直延伸下去的走道、樓梯、中庭和停車場，像一卷回憶錄影帶。

非官方的個人作品，與任何真實商場、品牌及公司無關；場景中的店名、品牌、車牌皆為虛構。

**桌機、手機、手把都能玩**（建議戴耳機）。桌機：WASD 走、滑鼠轉頭、Shift 跑。手機：觸控搖桿。

網址參數：`?vhs=0` 關掉錄影帶濾鏡、`?seed=123` 固定亂數。
