# 樓梯間（試玩）

單獨可玩的第一人稱恐怖小品：從井邊房放人偶下去，一路往下走，帶一件東西回來。聽聲音分辨下面有什麼，該停就停、該收就收。
非官方的個人作品，與任何商業遊戲及其公司無關；樓梯間的場景、怪物、聲音、文字皆為原創製作。
例外：走到最底層那扇門後面的村子（`samugiru/`）是《石器時代》村莊的同人重現，圖像與音樂取自該遊戲客戶端，版權屬原權利人，未經授權；權利人要求即撤下。

**手機、桌機都能玩**（建議戴耳機）。
- 手機：左半邊拖＝走、右半邊拖＝轉頭；右下「拾」撿東西、「燈」拉遮光板、「收」長按收回。iPhone 可「加入主畫面」以全螢幕玩。
- 桌機：WASD 走、滑鼠轉頭、F／Enter 撿、R 遮光板、按住 C 收回。

網址參數：`?save=0` 不讀不寫存檔、`?seed=123` 固定亂數。
